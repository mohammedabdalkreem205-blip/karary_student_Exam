# منصة امتحانات الباش مهندس محمد عبدالكريم محمد الإمام
**(طلاب جامعة كرري)**

## عن المنصة
منصة تعليمية تفاعلية مخصصة لطلاب جامعة كرري، تهدف إلى مساعدتهم على الاستعداد للامتحانات من خلال بيئة امتحان حقيقية، بنك أسئلة ضخم، تصحيح فوري، ومراجعة شاملة للأخطاء.

## المميزات التقنية
- **تصحيح آمن من الخادم:** التصحيح يتم في قاعدة البيانات لمنع أي محاولات غش.
- **لوحة تحكم متقدمة:** إحصائيات فورية، رسوم بيانية، وتصدير النتائج (CSV / PDF).
- **تحديث تلقائي (PWA):** المنصة تدعم العمل بدون إنترنت وتحدث نفسها تلقائياً لدى الطلاب بمجرد رفع أي تعديل.
- **تعدد المواد:** تدعم المنصة حالياً C++، إدارة الملفات، طرق البحث، تحليل النظم، والدراسات السودانية.

## البنية التحتية
- **الواجهة:** HTML5, CSS3, Vanilla JavaScript.
- **قاعدة البيانات:** Supabase (PostgreSQL).
- **الاستضافة:** GitHub Pages.
